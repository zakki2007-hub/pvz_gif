## 使用方法

- 单个 GIF：从上面的目录进入对应文件，在 GitHub 文件页打开原图或下载。
- 离线浏览：在仓库主页选择 **Code → Download ZIP**，解压后用浏览器打开根目录的 `index.html` 浏览僵尸，或打开 `plant_gifs/index.html` 浏览植物。两页均支持搜索。

发射类 GIF 展示植物本体动作。部分爆炸、冻结和出土效果由原游戏贴图、动作轨迹及粒子参数合成。游戏素材的权利归原权利人所有。
